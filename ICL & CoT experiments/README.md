# ICL & CoT Experiments

In-context learning (ICL) and Chain-of-Thought (CoT) experiments used to probe baselines across tasks.

## Structure
- `CoT/`: Unified batch runners for CoT experiments (`batch_parallel_unified.py`, `batch_tsnh_unified.py`).
- `ICL-python/`: Jupyter notebooks and prompts for several datasets.
- `outputs/`: Collected outputs grouped by model and dataset.

## Quick start
- Run notebooks in `ICL-python/` to reproduce ICL experiments.
- Use `CoT` batch scripts for scripted CoT runs.

See subfolder READMEs for details.
